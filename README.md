# The Data Portfolio — Big Mac Index Analysis

## Objective
Analyze the Big Mac Index to explore purchasing power parity, currency valuation, data structures, and missing data patterns across countries over time.

## Methodology
- Loaded the Big Mac Index dataset from The Economist's GitHub repository.
- Identified cross-sectional, time-series, and panel data structures.
- Calculated implied PPP exchange rates and currency valuation percentages relative to the U.S. dollar.
- Examined incomplete country panels and missing-data patterns.
- Classified Russia's exit from the dataset as MNAR.
- Created a bar chart of currency valuations and a time-series comparison across selected countries.

## Key Findings
- Switzerland was overvalued by approximately 41.8% in the July 2024 cross-section.
- Japan was undervalued on average across each decade in the dataset.
- Missing observations are not always random, so dropping incomplete panels may create selection bias.
- In my time-series comparison, Mexico showed the largest repricing in PPP valuation since 2010.
